# LiftAssistant specification workspace

Language-independent semantics and mappings will live here. Nothing is normative yet.

Initial subjects:
- domain vocabulary;
- capabilities;
- intents;
- observed state;
- authority;
- diagnostics;
- runtime semantics;
- mappings to existing standards.

Before inventing a concept, check SAREF4LIFT, BACnet, CiA 417, T/GSET 001-2025, Open-RMF/RFA and other established work.

Rust structs implement the model; they are not the specification itself.
